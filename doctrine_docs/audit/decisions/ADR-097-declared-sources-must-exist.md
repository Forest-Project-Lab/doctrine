# 宣言した出所が実在することを検める。認識の等級は検めない

## 背景

報告の RFC（設計方針の提案）第1節は「LLM が生む主張に `observed` / `inferred` /
`proposed` / `unknown` のいずれかを必須にし、**LLM 自身の文章を証拠に数えない**」を求める。

**測った。この体系で出所を記す欄は `sources` である**（必須キーの八番目。確定事実3）。
中身の実態は 322 件で、次のとおりだった。

| 形 | 件数 | 例 |
|---|---|---|
| **リポジトリ内の道** | **190（59%）** | `plugin/scripts/docs-audit.py` |
| 自由文 | 63（19%） | 上位設計書の節番号 |
| 文書 id | 25（7%） | `ADR-081` |
| URL | 25（7%） | 標準の配布元 |
| issue の番号 | 19（5%） | `doctrine#168` |

**そして `sources` は一件も検められていなかった。** 名前の似た `source_drift` は
`depends_on` の端の日付を見るだけで、`sources` を読まない。

**実測すると、6 件が実際に壊れていた。**

| 指している側 | 指した道 | 実際 |
|---|---|---|
| ADR 五本 | `model/research/RESEARCH-001-…` | **`model/archive/` へ退避していた** |
| ADR 一本 | `packaging/decisions/ADR-047-methodology-performance-noimpact.md` | **改名されていた** |

意味の等級（読んだのか、推論したのか）は機械では判じられない（非目標 第1項・第7項）。
**機械が検められるのは「指した道にファイルが在ること」だけである。**

なお、等級を散文で書く様式は既に一度使っている —— `RESEARCH-004` の「調査の方法と、その
証拠等級」が、文書ごとに「全文を読んだ／入口の本文を読んだ／実在と発行日だけ確認／未取得」
を分けて書いている。**様式は在る。機械の検めが無いだけである。**

## 却下した選択肢

**認識の分類を必須の欄にする（RFC の逐語）。** 埋める内容は在る（上記の様式）。だが
**機械が見られるのは欄が埋まっていることだけで、値の当否は見られない。** 値を検めない欄を
必須にすると、埋めれば通る儀式になる —— 非目標 第14項が同じ判断を下している
（検証できない申告は誤った安心の素になる）。**見ていないものを見ていると書かない。**

**`RESEARCH` に節として課す。** ADR-090 が「`RESEARCH` は形を課さない型」と決めた
（調査は探索であり、形が先に決まらない）。**置換しない。**

**ADR も検査の対象にする。** **直せない。** 受理済みの ADR は不変であり（Guard1）、
`sources` の道を直す carve-out は無い。**咎めても直す道が無い門は、門が邪魔者になる形**で
ある。しかも非目標 第12項が「旧 id を指し続ける参照は監査が事後に指す」と立場を既に
決めている。`source_drift` と孤児の検査も同じ理由で ADR と投影を除いており、
**同じファイルに前例が二箇所在る。**

**自由文・URL・文書 id も検める。** URL は通信しないので検められない（確定事実7）。
文書 id は死リンクの検査が既に見る。自由文は機械で判じられない。**形で絞る。**

**何もしない。** 190 件の申告が誰にも見られていない状態が続く。そして実際に 6 件壊れていた。

## 決定

**宣言した出所のうち、リポジトリ内の道の形をしたものが実在することを検める。
認識の等級は検めない。**

1. **`source_missing`（WARN）を足す。** 現行の文書（**ADR と投影を除く**）の `sources` の
   うち、リポジトリ内の道の形をしたものが実在しなければ挙げる。
2. **形で絞る。** 拡張子を持つ相対の道だけを対象にする。URL・文書 id・issue の番号・自由文は
   対象にしない。
3. **意味の等級は欄にしない。** 読んだのか推論したのかは散文で書く（`RESEARCH-004` の
   様式）。**機械は検めない**ことを仕様に明記する —— 検めない範囲を主張しないためである。
4. **ADR を対象にしない**（上記の理由）。いま壊れている 6 件は六本とも ADR であり、
   **この決定では直らない。** 記録として残す。
5. **既存の木で所見は増えない。** ADR を除くと壊れは 0 件である（実測）。

## 帰結

- 190 件の申告に、初めて機械の目が入る。ファイルを動かしたとき、指し続けている側が分かる。
- 保証限界: **在ることは、正しい出所であることではない。** 道が在っても、その中身が主張を
  支えているかは見ない。**RFC 第1節は部分的にしか満たさない** —— これを受入とは書かない。
- 保証限界: **認識の等級は機械が見ない。** 散文の様式は在るが、書かれているかも、書かれた
  等級が正しいかも検めない。人と `doc-review` が見る。
- 保証限界: **ADR の壊れた道は残る。** 不変なので直せない（非目標 第12項の立場）。
- 保証限界: 形の判定は拡張子に依る。拡張子を持たない道（ディレクトリ）は見ない。
  別の書き方で同じことをすれば掴めない。**機械で判じられる形に限る**という取引である。
