# 刻印の書式を外部の表示製品と共用する — doctrine は外部の刻印を検査しない

## 背景

刻印（ビューが記す参照時点）の書式の正本は ICD-005 の `view-stamp-format` である。しかし
宣言の対象は自リポジトリ内の体系外 .md（ADR-073）に限られ、**外部の表示製品が描いた
投影**が同じ書式を名乗ってよいかは定まっていない（issue #294 の観測。権限は ADR-151）。
定めないままだと、消費者ごとに独自の刻印が発明され、「いつの・どの木から描いたか」という
同じ思想が別々の書式で表現される。

## 却下した選択肢

- **外部は独自の刻印を持つと定める。** 書式が二つになる利得が無い。読み手（人と機械）は
  刻印を見るたびにどちらの書式かを判じることになる。
- **外部の刻印も doctrine の監査で検査する。** リポジトリを越えた統治はしない
  （NONGOAL-001。越境の参照は EXT アンカーで引く）。外部の成果物の検査は外部の仕事である。
- **何も定めない。** 現状のまま。外部の表示製品は書式を借りてよいのか分からず、
  自前の記録（実測 overlay の自前欄）が増え続ける。

## 決定

外部の表示製品（リポジトリの外の消費者）も `view-stamp-format` の書式を使ってよい、と
ICD-005 に宣言する。外部で使うときの意味は次のとおり。

1. `src` には消費者（製品）の名を書く（自リポジトリ内のビューが出所のリポジトリ名を
   書くのと同じ欄に、書き手の名が入る）。
2. `as-of` には参照した doctrine の参照点（tag と SHA（コミットを一意に指す指紋））を書く。
3. doctrine が検査するのは従来どおり自リポジトリ内のビューだけであり、**外部の刻印は
   検査しない**。書式の共用は検査の約束ではない。

## 帰結

- 位置づけ・出所・現行性という体系の思想が、外部の投影でも一つの書式で表現される。
- 外部の消費者は刻印の書式を発明せずに済み、自前の埋め合わせ欄を刻印へ寄せられる。
- 保証限界: 外部の刻印の正しさ・古びは外部の側の検査に委ねる。doctrine 側は書式の正本を
  提供するだけである。
