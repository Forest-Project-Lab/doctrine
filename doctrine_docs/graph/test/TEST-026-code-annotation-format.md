# コード注釈の書式の検証

SPEC-026 の走査と指紋を検証する。実装テストは `plugin/tests/test_tracescan.py`。`[R3][R4]`

## 受入基準への対応

- 注釈記号の異なる言語で同じ印が読めること。少なくとも `#`・`//`・`--`・`;`・`%`・ブロック注釈の六通りで確かめる。
- 印の行を指紋に含めないこと。印の注釈記号だけを書き換えても指紋が変わらないこと。
- 改行コードが CRLF でも改行一文字だけでも、同じ内容なら指紋が一致すること。行末の空白の有無で指紋が変わらないこと。
- 対応付けの誤りを、入れ子・両端の `id` の不一致・閉じ忘れ・開いていない `end` の四種に分けて挙げること。
- 統治木の中と `.md` を走査しないこと。バイナリを飛ばすこと。
- 上限を超えたときに、飛ばした事実を告げること（黙って切り詰めない）。
- 返す `path` が相対で、区切りが `/` であること。絶対パスも利用者名も含まないこと。
- 勘定の保存則が成り立つこと: 触れたファイル数 ＝ 寄与 ＋ 印なし ＋ 明示管理外 ＋ Σ 除外（ADR-058・ADR-067）。上限打ち切りの既知の残りも和に入ること。
- 統治外の宣言（ADR-067）: 宣言したファイルが第四項に数えられ、理由が任意であること。宣言と範囲の印の同居が warn（trace_exempt_conflict）で挙がり、範囲は実態として寄与に数えられること（指紋照合は無音のまま）。揺れた宣言が疑いになること。`--term exempt` で一覧が導出できること。
- 勘定に全規則の枠が 0 件でも在ること。枠の集合と除外規則の正本表が**両方向で**一致すること（表に規則を足すと、枠と試験を足すまで落ちる）。
- 名前付きパイプが根の配下にあっても走査が戻ること（開かずに除外へ数える）。
- 印なしが独立の項であること（規則の除外に紛れないこと）。印の語はあるが対を成さないファイルも印なしに数えること。
- 読めないファイル・読めないディレクトリ・降下しないシンボリックリンクが、それぞれ規則 id で数えられること。
- 根が統治木そのものでも、配下（サブディレクトリ含む）を走査しないこと。
- `--coverage` が件数を、`--coverage --term <項>` が当該の一覧を返すこと。表に無い項が使い方の誤り（終了コード 2）になること。一覧（members）は既定で持たないこと。
- 監査の要約に、走査が走ったときだけ `trace_coverage` が載り、opt-in が無ければ載らないこと。
- 編集時の促し（ADR-063）: 勘定のある要約の下で印の無いコードの編集に一度だけ出ること。勘定の無い要約・要約なし・印のあるコード・`.md`・統治木の中では黙ること。二度目のセッション内編集で黙ること（`plugin/tests/test_review_nudge.py` の TestCodeTraceNudge が凍結する）。
- 綴りの揺れの六変種（コロンの後の空白・小文字の id・下線の id・行頭の語文字・余計な語・id の欠落）が、それぞれ疑い（`trace_marker_suspect`）として挙がること（ADR-059）。
- 正しい印・印の語だけの散文・照合の原文の形が、疑いにならないこと。監査で疑いが advisory に留まり、合否（error/warn）を変えないこと。
- 監査が走査の切り詰め所見（`trace_scan_truncated`）を捨てず advisory で転記すること。
- リポジトリ自身の走査で疑いがゼロであること（原文に印の形を書かない規律。自己適用）。
- 設定の適用除外（ADR-072）: 完全一致と前置きの一致（末尾 `/`）が明示管理外へ分類され、保存則が保たれること。文字列でない・空の項目が捨てられること。未指定と空指定が同じ答えになること。一覧が求めに応じて導出されること（ConfigExemptTest が凍結する）。

## 退行観点

- 印の判定に言語ごとの分岐が入っていないこと。「範囲はどこか」の答えが一つの実装に留まること（ADR-054。ADR-049・ADR-053 と同じ欠陥類型を作らない）。
- 走査が統治木の中へ入らないこと。この書式を説明する文書自身の印を読まないこと（自己言及）。
- 一ファイルの誤りが、他のファイルの走査を巻き込まないこと。
- 走査が例外を外へ出さないこと。読めないファイルで止まらないこと。通常ファイル以外を開かないこと（開いて戻らなくなる経路を復活させない）。
- 返す値に絶対パス・機械固有の時刻が混じらないこと（機械をまたいで共有できる形を保つ）。
- 表に無い除外（規則 id を経由しない黙った除外）を作らないこと。監査の要約に一覧（members）を載せないこと（件数だけ。ADR-058）。

## 合否基準

全テストが成功し、六通りの注釈記号で同じ範囲が得られ、改行コードの違いで指紋が割れず、四種の対応付けの誤りがそれぞれ挙がり、勘定の保存則が全ての除外経路で成り立ったとき合格とする。
