# 悉皆トレース — 印なしゼロを選べる体系にする

## 変更内容

追跡の走査に、opt-in の悉皆モードを足す。このモードを入れた体系では「印なし」が
未決の残高として監査 warn になり、全ファイルが「注釈済み／理由つき統治外／規則に
よる除外」のどれかに落ちるまで残る。注釈を書き込めない媒体（テンプレート・
JSON・法的文書）の出口として、設定側の適用除外を足す。仕様側の悉皆が済んだ
体系には、鼓動が一度だけモードの存在を中立に案内する。

## 理由（要求元）

双方向トレースはこの体系の看板だが、自宅で印なし62ファイル。注釈が任意
（ADR-054）のままでは「未分類」と「意図した管理外」が区別できず、追跡の
グラフを消費する応用（要求→設計→実装→試験のドリルダウン表示・依存の可視化）
が成立しない。宇宙工学の追跡規律が信頼されるのは「未分類が存在しない」から
であり、その状態を選べるつまみが要る。既定は現状のまま（通常の導入先は静か）。

## 影響の初期見積

- 文書: ADR（新規1件）、SPEC-026（走査）、SPEC-011 と SPEC-021 は各ドメインの
  更新（検査名簿・鼓動の案内）、TEST-026・TEST-011・TEST-021。
- 実装: `_tracescan.py`（設定除外の分類）、`_audit_trace.py`（残高の warn）、
  `docs-audit.py`（設定キー）、`gov-heartbeat.py`（一度きりの案内）。
- 自己適用: 本リポジトリでモードを入れ、印なし62件をゼロへ落とす。
- ドメイン跨ぎ: audit（要約と検査。ICD-005 経由）と packaging（鼓動）。

## 実施の記録

2026-07-28 に完了。決定は ADR-072、影響の列挙は IMPACT-003。印なし62件は
範囲の注釈11本・ファイル内 exempt 27本・設定除外24件でゼロになり、悉皆モード
での全件監査が error 0 / warn 0 / advisory 0 であることを確認した。
