# H 層の判定を受けて意味モデルの器の凍結を解く（ADR-112 を置換）

## 背景

ADR-112 決定5 は、意味モデルの器（スキーマ）の凍結と、その解除条件を定めた——意味モデルが
最低二回改訂され、M 層（機械の門）を通過し、H 層（人間が重大な誤読を検める門）が
`UNASSESSED`（未評価）でなく合格した後、根拠 ADR の置換によってのみ解く。

issue #294 の実測では、三条件のうち未達は H 層の一つだけだった（改訂は Phase 1 と Phase 2 の
前半・後半で三度、M 層は doctrine-lens 側の 14 段・不変条件 30・検査器 33 が緑）。

2026-08-14、所有者が H 層の実施を報せた。模型の作成に関与していない者に、床（全読者共通の
合格線。ADR-160 決定2）の四つの問いを実際に問い、**太字の誤読は 0 件**であった。
**実施の逐次記録は取っていない**（口頭で実施し、記録の様式には起こしていない）。所有者は、
この段階を MVP（最小で価値を出す版）と位置づけ、証跡をこれ以上厚くするより前へ進めることを
優先する、と裁定した。

不変性ガードにより ADR-112 は編集できない。正規の道（ADR-044: マージ済みの ADR は後継で
置換する）に従い、本 ADR が置換する。

## 却下した選択肢

- **記録が起きるまで凍結を保つ。** 証跡の等級は上がるが、実施が済んだ後に様式の不足だけで
  止めることになる。所有者が MVP の位置づけと前進の優先を裁定した。
- **被験者を増やし、規格の相場（層ごと 15 名・85%・重大誤解 5% 未満など）に乗せてから解く。**
  ADR-160 決定6 のとおり、その水準は外へ保証を主張するときに要る。解除の判定に要るのは床の
  通過だけであり（ADR-160 決定3）、いま求められているのは保証の主張ではない。
- **記録が無いことを書かずに解く。** 後から証跡の等級を検められなくなる。被験者 0 人でも
  「重大誤読 0 件」が真になる空虚な真を潰した ADR-112 の趣旨に反する。等級は書いたうえで
  解く。
- **本 ADR で型を同時に増やす。** 一文書一決定に反し、解除の裁きと型の設計が混ざる。型は
  ADR-161 とその実施の波が担う。

## 決定

1. **H 層は合格と裁く。** 根拠は 2026-08-14 の所有者の報告である——模型の作成に関与して
   いない者へ床の四つの問いを実際に問い、逆読みは 0 件だった。**証跡の等級は「所有者の
   報告」であり、記録に裏づけられた合格ではない。** 逐次記録は残っておらず、第三者が後から
   検証することはできない。
2. **意味モデルの器の凍結（ADR-112 決定5）を解く。** 型・必須キー・置き場所の追加を、根拠
   ADR とその実施の波によって行ってよい。
3. **解除の範囲は器に限る。** 移管・製品採用・Marketplace（配布の場。固有名）公開は本 ADR の
   外であり、issue #210 の三条件と所有者の裁定に従う。
4. **ADR-111・ADR-112 の他の決定は現行のまま引き継ぐ**——宣言済みの読み口（ICD-002 の
   `trace-index-api`・`dependency-graph-api`）、保証状態の七状態、`planned` と検証戦略の
   対応、人間の沈黙を承認へ変換しないこと。**ICD-002 の宣言と、そこに書かれた根拠の参照は
   動かさない。** 根拠の連鎖は ADR-111 → ADR-112 → 本 ADR であり、`superseded_by` で機械的に
   辿れる。中身が一文字も変わらない参照の張り替えは、`updated` の追随を木の広い範囲へ波及
   させるだけである（実測: ICD-002 の日付を上げると追随の疑いが 9 件、その追随でさらに
   15 件が湧いた）。張り替えは、宣言そのものを変える波でまとめて行う。
5. **解除の後も守る規律**——正本は一つに保つこと、描画の向きは正本から投影への一方通行で
   あること（ADR-161）、依存グラフの辺を Flow へ自動変換しないこと（ADR-136 決定3）、
   起草は `proposed` 限定で確定の一押しは人が行うこと（ADR-136）。

## 帰結

- ADR-112 は `superseded_by: ADR-162` を付し superseded へ遷移する。ICD-002 の宣言は無変更で
  ある（決定4）。
- EXT-006 の期待（「H 層は `UNASSESSED` のまま維持されること」）を、実施済みと解除済みの
  記録へ書き換える。
- ADR-160（誤読の門を床と読者層に分ける）を受理する。ADR-161（意味モデルの正本の形）は、
  同 ADR の帰結のとおり実施の波と同じ日に受理する。本 ADR は型を一つも増やさない。
- 保証限界: 本 ADR が記録する H 層の合格は、所有者の報告の等級である。後の版で保証を外へ
  主張するなら、ADR-160 決定6 の言い方（層と人数の併記）に従い、記録を伴う実施をやり直す。
- 保証限界: 本 ADR は System Map の製品採用・正式移管について何も言わない。裁きは所有者に
  ある。
