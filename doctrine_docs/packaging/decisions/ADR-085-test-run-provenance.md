# 試験走行は判定の依り所を刷る。証跡は保存せず、走らせた場が持つ

## 背景

`ADR-081` は、宇宙機ソフトウェアの保証実務から採るものを三つ決めた。その一件目が
「検証結果を証跡として残す」である。根拠は JERG-2-610C（2025年3月28日 C改訂）の用語定義で
ある。

> **検証** 客観的証拠を提示することによって、規定要求事項が満たされていることを確認すること
> (JERG-0-049D、ISO9000)

同標準の 6.4 検証プロセスは三つのアクティビティからなる ——
「(1) プロセス開始の準備　(2) 検証　**(3) 検証結果の管理**」。この体系には (3) が無い。

**実害が出た。** 2026-08-02、`plugin/scripts/_hookio.py` の実行ビットは、手元では
**1036 件すべて緑**で、CI では**落ちた**。原因は `core.fileMode=false`（ディスクは 755 でも
git の索引は 644）である。同じ試験・同じ commit・違う判定。

「試験が通った」という主張が、**どの環境の話なのかを持っていなかった。**
その主張は JERG の定義でいう「客観的証拠の提示」を伴っていなかったので、
そもそも検証ではなかった。

## 却下した選択肢

**判定を成果物として保存する（`.claude/.cache` へ書く・リポジトリへ commit する）。**
この体系は導出値を保存しない（ADR-055。追跡の索引を保存しない決定と同じ理由）。保存すれば
第二の正本が生まれ、実体とのずれという新しい欠陥面を作る。加えて統治対象の機密が入りうる
（ADR-074 が許可制で防いだ経路を、こちらから開けることになる）。

**環境の差を潰す（`core.fileMode` を強制する・容器を固定する）。** 差を消せば今回の一件は
防げるが、次に判定を変える環境の性質（`PYTHONIOENCODING`・改行の扱い・Python の版・
実行環境の版）が現れたときに同じ驚きが起きる。**差を消すのではなく、差が読めるようにする。**

**全ての試験に環境を記録させる。** 一件ごとに書かせても読めない。走行ごとに一度でよい。

**監査に「証跡の無い判定」を検出させる。** 監査はセッション終端に走り、試験の走行を見て
いない。見ていないものを見ていると書かない（`NONGOAL-001` と同じ規律）。**この受入条件は
いま満たせない**ので、`#166` の受入から外し、保証限界として書く。

## 決定

**試験走行は、判定の依り所（走行の証跡）を最後に刷る。証跡は保存せず、走らせた場
（端末・CI のログ）が持つ。**

刷るのは、**判定を変えうるもの**に限る。飾りは入れない。

1. Python の版と実装（判定を変えた実例がある）
2. 実行環境の種別（OS の名と版）
3. プラグインの版
4. **判定を変える設定** —— `core.fileMode`（今回の一件）。ほかに見つかったら足す
5. 対象の commit（取れなければその旨）
6. 走行の結果（件数と PASS/FAIL。既存の要約を保つ）

制約:

- **保存しない。** 走行のたびに作り、走行のログへ刷るだけとする（ADR-055）。
- **統治対象の内容を入れない。** 刷るのは環境と版だけで、パス・文書の内容・リポジトリの
  名前は入れない（ADR-074 の許可制と同じ形）。作業ディレクトリも刷らない。
- 書式の正本は `SPEC-028` に一箇所だけ置く。lens 側の潰しの検査器が既に同じ形を持つ
  （Node の版・reporter・試験コマンド・対象 commit）。**同じ思想を二つの体系で二重定義しない**
  ため、doctrine 側の正本は SPEC-028 とし、lens 側は自分の SPEC-007 が持つ。

## 帰結

- 「1036 件すべて緑」と「CI で落ちた」を並べたとき、**どこが違ったのかがログから読める**。
  今回は `core.fileMode` の一行で足りた。
- `ADR-081` が採ると決めた三本柱の一件目が、実装の形を持つ。
- 保証限界: **証跡が在っても内容が真とは限らない。** 証跡は「この環境でこの版でこの判定が
  出た」以上を言わない。試験そのものが弱ければ、強い証跡が弱い主張を飾る（`#170` がその例で
  あり、行番号は数ヶ月ずれたまま試験は緑だった）。
- 保証限界: **証跡の無い判定を機械が咎めることはしない。** 監査は試験の走行を見ておらず、
  見ていないものを見ていると書かない。判定の依り所を刷るところまでが本 ADR の範囲である。
- 保証限界: 刷る項目は「いま判定を変えると分かっているもの」に限る。次に驚かされる性質は、
  驚いてから足す。**網羅を主張しない。**
