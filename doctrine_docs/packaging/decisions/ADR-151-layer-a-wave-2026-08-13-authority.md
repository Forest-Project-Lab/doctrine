# 2026-08-13 の一括波（#294 の受け）の権限を恒久記録する

## 背景

issue #294 は、System Map を doctrine 導入済みの任意プロジェクトで見える物にするために
上流へ要るもの（層A＝統治の実態の読み口の過不足）を洗い出した。所有者は 2026-08-13 の
会話で、洗い出しの確認と「目的達成に向けた改修の実施」を指示した。会話の指示は消えるので、
何をどこまで許したかを恒久記録する（ADR-145 と同じ型）。

## 却下した選択肢

- **裁定を項目ごとに逐次仰ぐ。** 文書追加の一波ごとに保証台帳の再判定の税が掛かる
  （INC-040。606 件中 42% が古び、約 78 分）。波を割るほど税が増える。
- **会話の記録だけに頼る。** ハーネスのメモリは環境と個人の事実に限る（確定事実9）。
  体系の決定は統治木に置く。

## 決定

所有者指示（2026-08-13、会話側）に基づき、次を一括の一波として実施する。

1. #294 への回答の投稿。返り値が測った木の版を名乗る提案は受諾、外部の消費者が描いた
   投影の刻印は共用の側、統治木の発見は問い合わせの口で、複数リポジトリの模型は
   複数リポジトリ受けで応える。
2. 外部読み口の進化規約の確定（ADR-152。DECIDED-001 の事実13）。
3. dep-graph の CLI 読み口の宣言と衛生（ADR-153）・統治木の発見の口（ADR-154）。
4. 宣言済みの読み口が測った木の版と作り手を名乗る（ADR-155・ADR-156）。
5. 刻印の共用（ADR-157）・map-draft-check の複数リポジトリ受け（ADR-158）・
   必須節の名を返す口（ADR-159）。
6. リリース 0.12.0 の実施と、#294・#212 への完了報告。

認めないもの: 文書の型・必須キーの変更（ADR-112 のスキーマ不変は維持）、
意味モデルの器（lens 側スキーマ）への変更、H 層の判定の代行。
期限: 本波の完了報告が #294 へ投稿されるまで。

## 帰結

- 本波の各 ADR は背景に本記録を引き、会話へ遡らずに権限を検められる。
- 判断の変更が要る事態（本記録の範囲を超える決定）が出たら、実装せず #294 へ戻す。
- 保証限界: 本記録は権限の記録であり、各決定の当否は各 ADR が負う。
