# 網羅台帳の決定論の運びは正本の規則へ一本化する

## 背景

ADR-134 が古びの選別を「引いた範囲」に限った直後に、決定論の運びの側で三つの
食い違いが測られた。

第一に、再判定の走らせ手（`map_coverage`）は、どの項を引き直すかの選別に
**索引全体の指紋の比較**を自前で持ったままだった。これは ADR-130 が却下し、
INC-025 で実害が測られ、ADR-134 が正本（`orchestrator.is_stale`）から取り除いた、
まさにその形である。いまの台帳ではこの選別は正本の計数とたまたま一致するが、
新しい文書や試験が入った途端に乖離し、**正本が挙げない項の再判定を黙って
買い直す**。規則の写しは正本と黙って乖離する —— 却下した形が実装に残る二例目で
ある（一例目は INC-025）。

第二に、決定論の再照合（`recheck_evidence`）は「実装・試験・証拠あり」だけを
掃いていた。「非該当で理由あり」は範囲外に置かれ、古びた終端 80 件がそのまま
残っていた（ADR-134 の帰結が「埋まっていない」と名指した穴）。ADR-134 はこの
80 件を「証拠ポインタを持たないため決定論では検めようがない」と書いたが、
**実測では違う** —— 三冊の非該当 81 件（jerg 18・stpa 25・cast 38）は全件が
根拠ポインタを evidence 欄に持つ。決定論で検められるのに、掃く口が緑しか
見ていなかった。

第三に、独立再判定（ADR-132）は無作為の抜取りしか持たなかった。再判定の契機が
満ちた項 —— 決定論の再照合が判定不能へ落とした項や、recheck_trigger に書かれた
条件が現に成立した項 —— を狙って再検する口が無く、契機が満ちても抜取りに
当たるまで再検されなかった。

## 却下した選択肢

- **`map_coverage` が古びの規則の写しを持つ**: 写しは正本と黙って乖離する
  （INC-025 の形そのもの）。import で正本の関数をそのまま使う。
- **非該当も評価で買い直す**: 根拠ポインタの再照合は決定論でできる（ADR-118）。
  費用ゼロで済むものに評価を買わない。
- **決定論の再照合が非該当や緑を新たに作れるようにする**: 決定論で言えるのは
  「根拠が消えた」ことだけである。「新たに実装された」「新たに範囲の外に
  なった」は評価の仕事であり、双方向に動かすと評価を買わずに終端が増える道が
  できる（ADR-133 が同じ理由で却下している）。
- **狙った項の再検を、台帳を手で書き換えて代える**: 実装者が評価者の判定を
  書き換えることになる（ADR-115）。再検は評価の口を通す。

## 決定

1. 再判定の選別は正本 `orchestrator.is_stale` へ**一本化**する。`map_coverage`
   は写しを持たず import で使い、対象は未割当の判定不能と、正本の規則で古びた
   非終端だけとする。索引全体の指紋の比較は選別からも消える。
2. 決定論の再照合は**「非該当で理由あり」も掃く**。正本の規則で古びた項の
   根拠ポインタを索引へ引き直し、一つでも解決すれば判定を保って指紋だけを
   現行へ揃える。一つも解決しなくなっていれば、履歴へ積んでから判定不能へ
   落とす。根拠ポインタの無い非該当には触らない（落とすと「根拠が消えた」を
   言っていないのに判定を消すことになる）。この口は片方向のまま —— 緑も非該当も
   増やさない。
3. 独立再判定は**標的モード**（`--keys`）を持つ。名指しの項だけを再検し、
   記録の形と、割れたら取り下げて未割当へ戻す規律は抜取りと同じとする。
   存在しない key・判定の無い key は誤りとして止める（黙って読み飛ばすと
   「名指しの項を再検した」という記録が嘘になる）。

## 帰結

- 選別と計数が同じ規則を読むので、正本が挙げない項の再判定を黙って買う形は
  塞がれた。古びの規則を変えるときに動かす場所は `orchestrator.is_stale`
  一箇所になる。
- 非該当 81 件が決定論の再照合の範囲に入った。根拠が現に解決する項は費用ゼロで
  古びが解け、根拠を失った項は判定不能として次の評価に並ぶ。ADR-134 の帰結の
  「埋まっていない」は、根拠ポインタの無い非該当が現れない限り埋まった。
- 標的モードで、再判定の契機が満ちた項を契機のうちに再検できる。抜取り
  （ADR-132）は残る —— 標的は契機の追跡であり、抜取りは質の測定である。
  役割は混ぜない。
- 実装が決定の却下項を採っていないかを戻して確かめる逆照合の経路は、依然として
  無い（ADR-134 の帰結のまま）。本件の第一の食い違いはその不在の二例目であり、
  経路の要否は開いたままである。
