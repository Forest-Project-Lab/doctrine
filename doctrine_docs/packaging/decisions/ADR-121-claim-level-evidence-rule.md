# 証拠の照合は主張を単位とし、解決しない出典は外して刻む（規則を一つに揃える）

## 背景

反幻覚の照合規則が二つに割れていた。網羅の割当（ADR-118）は解決しないポインタだけを
外して主張を残すのに、統制欠陥（ADR-117）は出典が一つでも解決しなければ主張ごと
却下していた。実際に、四つの出典のうち三つが実在し内容としても妥当な指摘が、
捏造された一つの鍵のために落ちた。

規範は判定の単位を示している。JERG（宇宙機関のソフトウェア開発標準）は「検証とは
客観的証拠を提示して規定要求事項が満たされていることを確認すること」（`L219`・
`L479-L481`・`L2491`）と定める。単位は**主張**であり、解決する出典を一つでも保つ
主張は証拠を提示している。実在しない出典が混じっていたことは記録の欠陥であって、
証拠の不在ではない。一方 CAST（システム理論に基づく事故分析）は「事故調査は、なぜ
欠陥が導入されたのかと、なぜ運用前に識別されなかったのかの両方を特定する」（`L3929`）と
求める。妥当な指摘を捨てれば、見逃しの理由を追う手掛かりも一緒に消える。

## 却下した選択肢

- **厳格側（一つでも解決しなければ却下）に揃える**: 証拠を提示している主張まで捨てる。
  規範が求める「見逃しの理由の特定」を自ら難しくする。
- **緩い側に揃えたうえで、欠陥を刻まない**: 捏造された出典が混じった主張と、すべて
  実在する主張が同じ重さになる。記録の欠陥が消える。
- **人が一件ずつ判ずる**: 判定が記録に残らず、急ぐときに緩む（ADR-117 と同じ理由）。

## 決定

1. 照合の単位は主張とする。統制欠陥も網羅の割当も、**解決する出典を一つでも保つ
   主張は残し、解決しない出典は外して記録する**。解決する出典がゼロの主張だけを
   却下する。
2. 出典を外した主張には `citation_defect` を刻む。**刻まれた主張だけでは事象を
   閉じられない。**
3. 事象を閉じる条件に四つ目を足す —— 事象の証拠が体系の中で確かめられること。
   構造化した `evidence_refs` の少なくとも一つが索引で解決するか、`evidence_kind`
   が体系の外の証拠（`external` / `conversational` / `measurement`）として宣言されて
   いること。
4. 監査は、要約を書けなかったときに終了コード 3 を返す。所見の重さとは分ける。

## 帰結

- 照合するのは構造化された `evidence_refs` だけで、自由文の `evidence` は走査しない。
  文中の語がたまたま実在の名前と一致する（`plugin` のような）偶然を証拠と取り違えない。
- 捏造された事象はここで止まる。実在しない機構は解決するポインタを持てず、宣言も
  持たない（事象 INC-013 の構造側の対策。憲章の一項による緩和は残すが、それだけに
  頼らない）。
- 体系の外の証拠は宣言で受ける。外部の issue・会話中の実測・時系列の測定は、
  何であるかを名指しさせたうえで通す（EXT アンカー・刻印と同じ流儀）。
- 監査の終了コードの変更は、明示されていた決定（「要約の書き込みに失敗しても 0 を
  保つ」）の置換である。根拠は STPA（システム理論に基づく危険要因分析）—— 送った
  コントロールアクションが守られたと仮定しない（`L143`）、フィードバックの欠如が
  欠陥のあるプロセスモデルを作る（`L552`）、提供しない状態を仮定で片付けない
  （`L859`）。統治の唯一の全体像を書けなかった実行が 0 を返すと、書けたときと外から
  区別がつかない。DECIDED-001 事実12「フックの境界は沈黙して開かない」とも整合する。
- 要約そのものと画面への表示は従来どおり出す。止めるのは沈黙であって、監査の本務では
  ない。
