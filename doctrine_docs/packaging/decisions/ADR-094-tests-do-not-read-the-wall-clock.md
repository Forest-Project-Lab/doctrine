# 試験は実時計を読まない。時計を固定できる呼び出しでは固定を機械が要求する

## 背景

**2026-08-03 に `main` が赤くなった。誰も何も変えていない。日付が進んだだけである。**

落ちたのは注入の試験 `test_fresh_progress_has_no_stagnation_note` である。原因は二つ重なって
いた。切り分けて実測した。

| 入れた状態 | 結果 |
|---|---|
| 時計の固定だけを足す | 通る |
| アサートの絞り込みだけを足す | 通る |
| **どちらも無い（`main` の状態）** | **落ちる** |

1. **時計の依存。** 試験は要約の `generated_at` を前の固定日（`2026-07-27`）に置き、
   呼び出しに時計を渡していなかった。注入は実時計と比べて鮮度の警告を出すので、
   **7 日が経った時点でその一行が湧いた。**
2. **部分文字列の取り違え。** アサートは `動いていない` の不在を見ていた。だが停滞の一行
   （`進捗が N 回の監査で動いていない`）と鮮度の警告（`SessionEnd の監査が動いていない
   可能性がある`）は**同じ部分文字列を含む**。別の機能の一行を掴んでいた。

**規約は既に在った。正本と機械の検めが無かった。** `plugin/tests/test_integration_e2e.py` の
説明文に「`generated_at`/`today` と review_by の計算は固定する。実時計を使わない」と書かれて
いたが、それは一つのファイルの説明文であり、他のファイルを縛っていない。**出所の無い規約が
一箇所に住んでいる形**であり、2026-08-02 に ADR-087・ADR-090 で二度直した形と同じである。

測った。**注入と鼓動は時計を固定する口を持っている。**

| 呼び出し | 時計を固定する口 |
|---|---|
| `docs-audit.py` | 在る |
| `inject-contract.py` | 在る |
| `gov-heartbeat.py` | 在る |
| `review-nudge.py` | **無い** |
| `capture-nudge.py` | **無い** |

そして固定日の要約を渡している試験ファイルは 6 本ある。うち 5 本は固定していた。
**落ちた 1 本だけが固定していなかった。**

## 却下した選択肢

**落ちた試験だけを直す。** 同じ罠は誰でも踏む。固定を忘れても**その日は通る**ので、
書いた本人には見えない。**時が経ってから、無関係な変更の取り込み依頼（PR）で赤くなる。**
原因が「日付が進んだこと」だと気づくまでの費用が高い（今日それを払った）。

**すべての試験で日付を今日から相対に作る。** 344 個の固定日を相対式に置き換えることになる。
固定日は**決定的であることの根拠**でもあり（同じ入力に同じ答え）、相対式はそれを崩す。
崩すべきは固定日ではなく、**固定日と実時計を比べること**である。

**時計を固定する口を全ての呼び出しへ足す。** `review-nudge` と `capture-nudge` は日付の
計算をしていない。**要らない口を配らない**（ADR-084 の規律）。要るようになったときに足す。

**説明文の規約のままにする。** 一つのファイルの説明文は、他のファイルを縛らない。
実際に縛れていなかった（だから落ちた）。**在ることと効くことを分けない。**

**アサートの絞り込みだけで済ませる。** 実測では絞り込みだけでも通る。だが**時計の依存は
残る** —— 次に鮮度以外の日付依存の一行が増えたとき、また同じ形で落ちる。原因が二つある
ので、二つ直す。

## 決定

**試験は実時計を読まない。時計を固定する口を持つ呼び出しに固定日の要約を渡す試験は、
時計の固定を機械が要求する。**

1. **落ちた試験を二箇所とも直す。** 時計を固定し、アサートを停滞の一行だけに絞る。
   （絞り込みは ADR-082 と同じ取り違えの形である —— 部分文字列で別のものを掴まない。）
2. **機械の歯止めを置く。** メタの受入（`test_meta.py`。受入は TEST-020 が持つ）に一件
   足す —— 試験ファイルが (a) 固定日の `generated_at` を埋め込み、かつ (b) 時計を固定する
   口を持つ呼び出しを起動しているなら、**その固定を渡していること**を要求する。
3. **歯止めは自分で広がる。** 対象は「口を持つ呼び出し」で決める。呼び出しが後から口を
   得れば、その試験も自動で対象に入る。**免除の一覧を持たない。**
4. **口を持たない呼び出しは対象にしない。** `review-nudge`・`capture-nudge` は日付の計算を
   しないので、擬陽性を作らない。
5. **戻さない事項として記録する。** 「試験は実時計に依ってはならない」を横断の退行監視へ
   置く。

## 帰結

- 日付が進んだだけで門が赤くなる形が閉じる。**門が自分で壊れない。**
- 規約の正本がコードの中の検査になる。説明文の規約が一箇所に住む形が消える。
- 保証限界: **歯止めが見るのは「固定を渡しているか」だけである。** 渡した固定日が
  妥当かは見ない（ずっと前の固定日でも通る）。日付の意味の当否は人が見る。
- 保証限界: 固定日の埋め込みは、文字列の見た目（`generated_at`）で判ずる。別の名で同じ
  ことをすれば掴めない。**機械で判じられる形に限る**という取引である。
- 保証限界: 実時計に依る試験は、この形以外にもありうる（例: ファイルの更新時刻、乱数）。
  歯止めが覆うのは、要約の鮮度に関わる形だけである。**覆っていない範囲を主張しない。**
