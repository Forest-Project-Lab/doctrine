# 全スクリプトは標準ライブラリだけで動く(追認)

## 背景

「pip にも通信にも依存しない」は仕様(§4.3)と SPEC-020 に書かれ、決定事実(DECIDED-001 事実7)にも載る運用済みの決定だが、根拠として挙げられていた ADR-011 にはこの決定の記述が無かった。決定事実の運用契約(「決定を変えるときは根拠 ADR を置換する」)が、この事実については成立していなかった。

## 却下した選択肢

- 依存を許す(PyYAML 等): 導入先の環境差・通信断で毎ターンの Hook が壊れる。導入の壁になる。
- 根拠なしのまま運用を続ける: この決定を正規の手続きで変える道が無いままになる。

## 決定

同梱の全スクリプト(`plugin/scripts/` とリポジトリ直下 `scripts/`)は、標準ライブラリだけで動く。pip の導入も通信も要さない。フロントマターはフラットに限り、最小パーサで読む(§4.3)。

## 帰結

- DECIDED-001 事実7 の根拠を本 ADR に張り替える。
- 依存を足す変更は本 ADR の置換を要する。
