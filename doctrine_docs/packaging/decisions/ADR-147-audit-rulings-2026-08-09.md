# 独立再監査 2026-08-09 の所有者裁定を恒久記録する

## 背景

2026-08-09 に、前回の一括是正キャンペーン（PR（Pull Request。変更の提案）#254〜#266・tag v0.11.0・ADR-135〜145）の独立再監査を行った。その途中で所有者が五つの裁定を会話で下した。

会話は正本ではない（ADR-035）。ADR-145 が同じ形で前回のキャンペーンの権限を記録したので、本 ADR がその前例に倣う。裁定そのものの監査証跡は `assurance/ledger/rulings/2026-08-09-owner-decisions-delegated.json` に一件ずつの根拠つきで残してある。

## 却下した選択肢

- **記録しない**。会話の記憶に依存する運用へ戻る。ADR-035 と ADR-145 が既に禁じた形である。
- **運転手順（SKILL。開発専用の作業手順を運ぶ配布外の文書）へ書く**。SKILL は決定の正本ではなく、決定の正本ではない。前回 §7.2 が時限許可を持ち、期限どおり削除された（ADR-145）。決定は統治木に置く。
- **台帳の裁定ファイルだけに置く**。台帳は保証レーンの証拠であって統治木の外にある。決定の正本は統治木の側に要る。

## 決定

次の五つを記録する。

1. **実測を全部先に凍結してから修正へ入る。** 網羅の再判定を要する増減を再判定の前に入れる罠（ADR-134）を、順序で構造的に避ける。
2. **#197 のカルク軸の是正は、配布境界の所有者判断行に触れても自律で着地してよい。** 利用者の指摘内容が変わる更新であり、通常なら六類型の「配布境界や保証範囲の変更」に当たる（ADR-127）。本件に限り開放した。
3. **所有者判断 12 件の裁定を委任する。** 運転手順 §7 の「判断を仰いで止まる」を本件に限り解除した。裁定の内訳は採択 8・縮小採択 1・却下 2・類型訂正 1 で、根拠は裁定ファイルに一件ずつ書いた。
4. **文書変更は一括にまとめ、網羅の再判定は最後に一度だけ回す。** 文書を一件足すと網羅台帳 605 件がすべて古びる（実測）。ADR-134 の範囲限定は試験・技能では効いているが、文書では効いていない。
5. **索引の試験件数を直したうえで、240 件の「実装・試験・証拠あり」を再判定する。** 索引が試験を 0 件と数え、その虚偽が全評価プロンプトへ入っていた（INC-029）。その入力の下で下された判定を引き直す。

期限は本再監査の終了報告の merge とする。ADR は残す（ADR-145 と同じ）。

## 帰結

- 委任（3）は本再監査に限る。以後の所有者判断は運転手順 §7 に戻り、判断を仰いで止まる。
- （2）の開放も本再監査に限る。以後、利用者の指摘内容が変わる更新は六類型を名指して所有者判断へ回す。
- （4）は ADR-134 の限界の申告でもある。文書カテゴリの範囲限定は未解決の問いとして残る —— 直すなら引いた文書単位の指紋へ細かくする案があるが、規準の変更そのものが一度の再判定を要する。
- （5）の再判定は、文書一括がすべて着地してから回す。回すまで、網羅台帳の健全性は UNKNOWN（判定不能）の側に置く。
