# 門の判定は三値とし、検査が成立していないときは適合にも不適合にも数えない

## 背景

体系は状態語彙に UNASSESSED（前提欠如で未評価）を持ち、「前提が欠けたら
PASS（適合の証拠あり）ではなく UNASSESSED へ倒す」と決めている。ADR-114 は保証レーンに
ついてそう書き、ADR-116 は評価 model について同じ形を採った。

ところが merge の門は二値でしか書かれていなかった。常設許可の条件は「変更取り込み依頼の
検査が pass」であり、**検査が実行されなかった場合にどちらへ倒すかを書いていない**。

2026-08-06 に実際に踏んだ。外部の実行基盤が障害となり、検査は「pass ではない」状態で
返ってきたが、ジョブは一度も実行されていなかった（注記が
`The job was not acquired by Runner of type hosted` で、所要はどれも打ち切りの 15 分）。
このとき手元の全門は緑だったので、**「実質は緑だから通してよい」と読む圧力が生じた**。
逆に「pass でないから赤」と読めば、FAIL（走ったが不適合）と、実行が成立しなかった状態と
が同じ顔になる。どちらへ倒すかの規律が無く、判断が運転者のその場の裁量へ落ちた
（事象 INC-022）。

同じ局面でもう一つ出た。遅れて届いた検査が成功したとき、その**検査対象の識別子が変更取り
込み依頼の先端と食い違っていた**。木の内容は同じだったが、検査を通ったのは別の識別子である。
門は「pass したか」しか問わず、「何に対する pass か」を照合する義務を持っていなかった。

## 却下した選択肢

- **実行基盤の生存を体系が検出する**: NONGOAL-001 第14項が「継続的結合（CI）の敷設・稼働は
  検出しない。感知できるのは残した成果物までであり、それは敷設の証跡ではない」と決めている。
  非目標を覆すには別の決定が要り、しかも外部環境の感知という手段を体系は持たない。
- **走らなかった検査を赤として扱う**: 安全側に見えるが、走ったうえでの不適合と区別が
  付かなくなる。区別が付かない状態を作らないことは、この体系が繰り返し採ってきた形である
  （ADR-119 が不実行と書き込み失敗を分けたのと同じ）。
- **運転者の判断に任せ、そのつど記録する**: それが起きたことそのものである。記録は残ったが、
  同じ状況で別の運転者・別のセッションが別の結論を出しうる状態は残る。
- **判定を人が毎回手で照合する**: 実際に手で照合して食い違いを見つけたが、手順に無い義務は
  次の運転者へ渡らない。

## 決定

門の判定は三値（PASS / FAIL / UNASSESSED）とする。適合を採るには次をすべて満たす。

1. 検査が**実行されている**。ジョブが取得されなかったことを示す注記を持つ結果は、
   適合にも不適合にも数えない。
2. 同一の実行について、照会経路の返す状態語が**割れていない**。割れていたらどれも信じない。
3. **検査対象の識別子が、適用対象の識別子と一致する**。一致しないものは通さない。
4. 走り終わっていて、結論が既知の語彙にある。知らない語を適合と読まない。

実行されたうえでの不適合だけが FAIL である。それ以外の不成立はすべて UNASSESSED へ倒す。

判定は純関数に閉じ、収集だけが外部へ出る（`assurance/harness/merge_gate.py` の
`judge` と `collect`）。決定論試験は `judge` を固定した入力で凍結し、通信に依存する
試験を作らない。

## 帰結

- 理由は**全部**返す。一つ直せば通ると読ませないため —— 欠けている前提が複数あるとき、
  先頭だけを見て引き直すと同じ場所で二度止まる。
- 終了コードはレーンの他の実行器と揃える（0=適合 / 2=不適合 / 3=前提欠如）。
- **UNASSESSED は待機を意味し、迂回を意味しない。**引き直すか、待つか、事象として積むか
  のいずれかであって、手元の門が緑であることを理由に通してよいという意味ではない。
- 事故分析が出した五つの先行指標のうち、ここが機械化するのは三つである。残る二つ
  ——「イベントから実行生成までの遅延」と「二値語彙だけで書かれた条項の残存数」—— は
  見ない。前者は時刻の観測が要り、後者は散文の走査であって別の経路が持つ。
  **見ていないものを見ていると書かない。**
- この門は開発レーンの物であり、配布物には入らない。利用者の実行基盤を体系が観測する
  ことにはならない（NONGOAL-001 第14項を動かさない）。
