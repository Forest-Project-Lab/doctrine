# 2026-08-07 の一括是正キャンペーンの権限記録 — 誰が・何を・いつまで認めたか

## 背景

2026-08-07、所有者は会話での明示指示により一括是正キャンペーンを承認した。
射程は台帳の激変を伴う —— 一日のうちに複数の ADR・リリース・
PAUSED（保留の印が付いた範囲）への変更・反復分量の目安の超過が起きる。権限が会話にだけあると、将来の監査は
この激変を規律違反と読む。また会話の記憶に依存する形は、体系が既に禁じて
いる（ADR-035: 決定の正本は統治木に置く）。権限の記録そのものを統治木へ
一件の決定として残すのが本 ADR である。

## 却下した選択肢

- **記録しない**: 将来の監査が台帳の激変を違反と読む。裁定が在ったことを
  示す物が会話の外に無い。
- **SKILL（開発専用の運転手順の手順書）だけに書く**: 運転手順は配布物では
  なく、時限の節は期限後に削除される。削除された後、履歴に権限の記録が
  残らない。
- **会話の記憶に依存する**: ADR-035 違反。セッションを跨いだ再開は台帳と
  正本が持つと決めており、会話は正本ではない。

## 決定

2026-08-07 の一括是正キャンペーンの権限を次のとおり記録する。

- **誰が**: 所有者（会話での明示指示。2026-08-07）。
- **何を**:
  1. Phase 2 生成器を配布 8 個目の技能として出す（ADR-136 が実施）。
  2. FORMALIZE（検証計画の審査）・VERIFY（修正の独立検証）の両実装
     （ADR-138/139 が実施）。
  3. 受理済み文書の修復路は後継 ADR 一本を維持（WATCH-001 第13項が実施）。
  4. 一括の射程は全部 —— 決定論と SDK（実 Claude の評価セッション）の両方。
     cast 再判定・推奨全件トリアージを含む。
  5. 本計画の承認をもって: リリース 0.11.0 の実施・issue #210 への doctrine 側
     入力の投稿（2026-08-04 の停止指示の解除）・SKILL §7.2 の時限許可。
- **期限**: キャンペーン終了報告の merge まで。
- **認めないもの**: 評価 model 最低線の引き下げ（ADR-116）・merge 門の緩和。

裁定の監査証跡は `assurance/ledger/rulings/2026-08-07-bulk-campaign.json` に
置く。行動は本 ADR と SKILL §7.2 が運び、正本の行動導出は裁定の JSON を
読まない —— 読ませると、期限を過ぎた裁定が機械の中で生き続ける。

## 帰結

- 運転手順に §7.2（時限の許可）が入り、反復分量の目安の超過と PAUSED の範囲
  （Lens Phase 2 / overlay / System Map）への変更が期限内だけ認められる。
  期限後、§7.2 の節は削除される。本 ADR は削除されず、権限が在ったことの
  記録として残る。
- 台帳種別 `rulings/<日付>-<件名>.json` が正本の宣言（ADR-124 の二分）に
  「読まない理由」つきで載る。
- 期限後にこの権限の続きを要する者は、新しい裁定を要す。本 ADR は権限の
  履歴の記録であって、将来の権限の根拠ではない。
