# Hook 設定はセッション開始時に固定される前提で運用する(追認)

## 背景

「Hook の設定はセッション開始時に読み込まれ、以後固定される」は Claude Code の挙動に由来する運用前提で、仕様(§5)・SPEC-019・決定事実(DECIDED-001 事実8)に載っていたが、根拠として挙げられた ADR-011 にはこの記述が無かった。

## 却下した選択肢

- 即時反映を前提に運用する: 実行環境の挙動に反する。ガードを変えた直後の編集が旧設定で通る。
- 根拠なしのまま運用を続ける: 前提が変わったときに置換すべき決定が無い。

## 決定

Hook の設定(ガード・リンタ・注入・監査・ハートビート・捕捉の配線)はセッション開始時に固定される前提で運用する。設定を変えたら、新しいセッションで反映を確かめる。この前提自体は実行環境(Claude Code)の仕様であり、機械で追えないため、EXT アンカー(EXT-001)の `review_by` で定期再検証する(ADR-026)。

## 帰結

- DECIDED-001 事実8 の根拠を ADR-010(7技能固定)と本 ADR に張り替える。
- 実行環境がこの挙動を変えたら、EXT-001 の再検証で拾い、本 ADR を置換する。
