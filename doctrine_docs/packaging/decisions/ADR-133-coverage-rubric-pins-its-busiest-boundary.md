# 網羅の採点規準は最も使われる境界を明文で決め、機械で決まる床だけをコードで守る

## 背景

抜取りの独立再判定（ADR-132）を初めて走らせたところ、標本 25 件のうち 7 件で
判定が割れた。向きは対称で、速さによる劣化ではなかった。割れた 7 件は**すべて
一つの境界**に集まっていた —— 「その原則を求める決定や仕様が現に在る」ことを
『実装・試験・証拠あり』と読むか『対応計画あり』と読むか（INC-024）。

規準の文面はこの境界を決めていなかった。『実装・試験・証拠あり』は「実装され、
試験があり、証拠を指せる」と書かれ、証拠として文書 id を挙げてよいことになって
いた。決定の id を挙げれば「証拠を指せる」は満たされるので、決定が在るだけの
原則が緑になりうる。

実例では、上流工程を飛ばさないことを求める原則に対し、束の判定は監査の検査
`adr_not_landed` を証拠に緑を採り、独立の判定は「これらは事後の欠落検出であり、
工程を止める門は索引に無い」として計画側を採った。**どちらの読みも文面に収まる。**
だから人が裁く材料も無かった。

## 却下した選択肢

- **五値を割って粒度を増やす**: 境界が決まっていないまま区分だけ増やすと、
  迷う場所が増える。決めるべきは区分の数ではなく分岐の述語である。
- **幅（値と再現回数の対）だけを持って規準は直さない**: 数字は正直になるが、
  原因は残る。以後の判定も同じ境界で割れ続け、幅を測る費用が恒久的にかかる。
- **境界を機械だけで決める**: 挙げられた機構が原則の求めることを実際に果たして
  いるかは意味の判断であり、機械では閉じない（NONGOAL-001 第1項）。全部を
  コードで決めたことにすると、決めていないものを決めたと言うことになる。
- **決定論の照合で緑を増やせるようにする**: 「証拠が消えた」は決定論で言えるが、
  「新たに実装された」は言えない。双方向に動かすと、評価を買わずに緑が増える道が
  できる。

## 決定

1. 規準に**境界の判定規則**を明文で足す（規則を足す変更であり、既存の
   「緑へ倒さない」を消さない）:
   - 決定や仕様だけを証拠にして『実装・試験・証拠あり』を採らない。決定は
     「そう決めた」ことの記録であって、決めたことが現に効いている証拠ではない。
   - 事後に検出する機構を、事前に阻止することを求める原則の証拠にしない。
     検出は阻止ではない。
   - 挙げた機構が原則の求めることの一部しか果たさないなら『対応計画あり』とし、
     gap に残りを書く。
   - 話題が同じだけの機構を証拠にしない。
2. **機械で決まる床だけをコードで守る**。解決した証拠が文書 id（と .md の場所）
   だけの割当は『実装・試験・証拠あり』を採れず、『対応計画あり』へ落ちる。
   ADR-118 が「解決しないポインタしか無い緑」を判定不能へ落としたのと同じ形を、
   一段内側の境界に当てる。**床は規準の全部ではない** —— 機構の当てはまりの
   良し悪しは規準の文と抜取りの独立再判定が受け持つ。
3. 規準の**指紋を本文から導く**（`rubric_fingerprint`）。手で書いた版番号は本文と
   ずれる（導入複製が版番号を据え置いたまま中身だけ古びた INC-019 と同じ形）。
   判定にはこの指紋を刻み、どの規準に対する判定かを後から言えるようにする。
4. 終端の判定を評価を買わずに引き直す口を持つ（`recheck_evidence.py`）。
   ADR-130 は「決定論の再照合で足りる」と書きながら走らせ手を作っていなかった。
   この口は**片方向にしか動かさない** —— 証拠が消えた項を落とすだけで、緑を
   増やさない。

## 帰結

- 実測で、既存の緑 251 件のうち **13 件**（cast 7・jerg 4・stpa 2）が決定・仕様
  だけを証拠にしていた。決定論の照合で『対応計画あり』へ落とし、緑は 238 件に
  なった。評価の費用はゼロである。
- 規準が変わったので、以後の判定は前の判定と**別の規準に対する主張**になる。
  指紋を刻んだことで、どちらの規準で判じた項かを後から分けられる。
- **INC-024 はこれで閉じない。**床が落とせるのは「決定しか挙げられていない」と
  いう、読まなくても判る形だけである。観測された不一致 7 件のうち、床が捕まえる
  形のものは無かった（いずれも実在する検査を証拠に挙げていた）。残る幅は規準の
  文が縮め、抜取りの独立再判定が測る。**縮めたと書いて、消したと書かない。**
- 決定論の口が在ることで、統治木が動くたびに終端の緑を無償で引き直せる。
  ADR-130 が残した「走らせ手の無い 307 件」の穴が埋まる。
