# 用語チェッカーのテスト計画

## 受入基準への対応

- SPEC-008 の四つの照合規則 `BANNED_SYNONYM`・`CALQUE`[R10]・`CALQUE_WORDTRAP`・`UNDEFINED_TERM`[R6] を、発火すべき入力と発火すべきでない入力の両方で確認する。
- 種子への切り替えを確認する。運用辞書が無いときは種子を使うこと、解析に失敗したときは種子を使ったうえで `GLOSSARY_PARSE_ERROR` を添えることである。あわせて、型による飛ばしを確認する。GLOSSARY 正本・投影（OVERVIEW／CTXMAP）に加え、RESEARCH・ARCHIVE（`llm_context: never`）の本文も、禁止同義語を含んでも点検を飛ばすこと（ADR-023）である。

## 退行観点

- `入出力`の中の`出力`、`現在形`の中の`現在`を誤検出しないこと（複合語の覆い隠し）。WATCH に挙げた懸念事項と突き合わせて確かめる。
- 雛形が定める節見出し「却下した選択肢」の中の部分文字列を誤検出しないこと。その語を禁止同義語に持つ見本の辞書を立てて確かめ、単独で現れたときは引き続き咎めることも併せて見る（ADR-082。WATCH 第2項）。
- 登録簿の必須節名は、どの型のどの節名を利用者の辞書が禁じても書けること（ADR-135・ADR-146。#197）。**表A（禁止同義語）だけでなく表B（カルク）でも**確かめる —— 表A だけを見ていたため、カルクの側で 55 節名中 52 件が不可書のまま残っていた（2026-08-09 の実測）。あわせて、節名を含むだけのより長い禁止語が覆いに飲まれず発火することを全節名の軸で確かめる（ADR-146）。例ではなく全型・全節名の性質で確かめ、地の文の単独語は引き続き咎めること、登録簿が読めない環境では覆いが従来の源だけへ退いて落ちないことも併せて見る。
- 報告する行番号がファイルの行番号であること（ADR-083）。フロントマターの後ろの空行を変えて本文の開始行を動かし、**報告された行を開くとそこに咎めた語が在る**ことを見る。フロントマターの無い文書では換算しないこと、行を持たない助言は `None` のまま返ることも併せて見る。
- 固有名の照合除外（ADR-018）: 意味欄が「固有名」の行を `proper_nouns` として読むこと。登録した固有名の中の禁止同義語は弾かず、地の文の単独出現は弾くこと。禁止同義語を包含する登録済み承認語も、辞書登録だけで照合から外れること。
- 末尾注記の場合分け: 「可」を含む注記は文字列照合の対象にせず、含まない注記は素のトークンを照合すること。
- 辞書を二重に定義しない、すなわち承認語表をハードコードしないこと[R6]。

## 合否基準

- `tests/test_termcheck.py` が全観点で合格すること。期待どおりのコード・重大度・行番号で発火し、擬陽性が無いことを合格とする。
