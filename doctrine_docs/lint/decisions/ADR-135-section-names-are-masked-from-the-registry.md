# 必須節の名の覆いは登録簿から導く（手写しの一覧をやめる）

## 背景

利用者の辞書が節名の語を禁じると、二つの ERROR（誤り）が互いを打ち消す（#197）。節名を書くと
`BANNED_SYNONYM` が落とし、書かないと `MISSING_SECTION` が落とす。どちらも ERROR なので
一括点検は必ず赤になり、**書き手に逃げ道が無い**。

この形は既に一度踏まれ、ADR-082 が『選択肢』を覆いの一覧へ手で足した。同 ADR は保証限界に
「一覧は手で保つ。**次の語で同じ取り違えが起きる**」と書いていた —— 起きた。#197 の実測
（doctrine-lens の辞書、承認語 42・禁止同義語 73）では、登録簿が定める必須節名のうち
『影響するテスト』『エラー時挙動』が素通しで、85 文書 241 件の ERROR のうち 20 件が
この形だった。節名の正本は登録簿（`_registry.REQUIRED_SECTIONS`）であり、書き手は
言い換えられない。**言い換えられないものを、禁止同義語の照合に掛けない。**

## 却下した選択肢

- **利用者側の辞書に固有名行として節名を写す。** #197 の報告者が回避に使った形。節名の
  正本が登録簿に在るのに辞書へ名を写すことになり、二重定義をしない規範（§4.3）と擦れる。
  どの節名が衝突するかを利用者の体系ごとに見つけて登録し直すことにもなる。
- **節名の断片も覆う。** 断片は利用者の文章に出てくる普通の語であり、覆えば地の文の
  違反を見逃す。覆いへ加えてよいのは本プラグインの雛形・仕様が定める語だけ（ADR-082 の
  判定基準）。
- **見出し行だけ覆う。** 本プラグインの技能・雛形は節名を地の文でも列挙する（「背景・
  却下した選択肢・決定・帰結」）。見出し限定では列挙が咎められ、誤警報を許さない方針
  （ADR-082）に反する。
- **ADR-082 を置換する。** あの決定の二経路（雛形語彙の覆い・接尾の除外）は現行のまま
  成り立つ。変えるのは覆いの**保守の道**だけであり、置換ではなく補強で足りる。

## 決定

`_mask_approved_compounds` の覆いの源に、登録簿の必須節の**完全な名**（全型ぶん。
`_registry_section_names()`）を加える。登録簿が節名を増減すれば、覆いが自動で追随する。
手書きの一覧（`_APPROVED_COMPOUNDS`）に残るのは、登録簿が知らない雛形語彙だけとする。
登録簿が読めない環境では、覆いは従来の源だけへ退き、沈黙して広がらない。

## 帰結

- 利用者の辞書が何を禁じても、構造語彙は常に書ける（#197 の袋小路の解消）。地の文に
  単独で現れた禁止同義語は従来どおり咎める。
- 保証限界: 一語の節名（決定・背景・帰結・前提・手順・制約 等）を利用者の辞書が禁じた
  場合、その語は本文のどこに現れても照合から外れる。構造語彙が常に書けることの意図した
  代償であり、精度を再現率より上に置く方針（ADR-082）の内側にある。
- 保証限界: 登録簿が読めない環境では節名の覆いは働かない。ただし袋小路の対
  （`MISSING_SECTION`）も登録簿由来なので、対で現れることはない。
- WATCH-001 第2項の保守の道を「登録簿から導く」へ更新する。節名を手で一つずつ足す形へ
  戻してはならない。
