# 覆いは最長の字面に譲り、門を閉じる照合すべてに掛ける（ADR-135 を置換）

## 背景

ADR-135 は #197 の袋小路を解いた。必須節の完全な名を登録簿から導いて覆い、利用者の辞書が節名の語を禁じても節見出しが書けるようにした。

2026-08-09 の独立再監査が、その解決に二つの穴を実測した。

一つ目。覆いは `_check_banned_synonyms` の中でしか掛かっていない。`_check_calque` は覆いのかかっていない本文に素の部分一致を当て、同じ重さ（点検の重さは二段ある。門を閉じる方と、門を閉じずに助言だけ残す方。ここで問題になるのは前者だけである）の所見を出す。よって利用者のカルク表（表B）が節名を挙げると、節を書けばカルクの所見・消せば節の欠落の所見で、#197 と同一の逃げ場のない板挟みになる。全型を掃引した実測は **55 節名スロット中 52 件が不可書**（16 型中 15 型が 100%）である。カルクは素の部分一致なので `エラー時`（`エラー時挙動` に含まれる）のような断片でも発火し、禁止同義語の側より射程が広い。

二つ目。覆いは仲裁を持たない全文置換であり、節名を含むだけの**より長い**禁止語まで黙って無効にする。`理由付け`（`理由` を含む）や `エラーハンドリング`（`エラー` を含む）を利用者が禁じても発火しない。ADR-135 の帰結が申告した限界は「節名そのものを利用者の辞書が禁じた場合」だけで、これは含まれていなかった。**申告していなかった見逃し**である。

二つは同じ根から出ている。ADR-135 は「言い換えられないものを照合に掛けない」という正しい論法を、一つの検査にだけ適用し、覆いと照合の優先関係を決めなかった。

## 却下した選択肢

- **カルクの側だけを同じ形で足す**（`_check_calque` にも覆いを掛ける）。一つ目は直るが二つ目が残る。次に門を閉じる検査が増えたとき、また運び忘れる。
- **見出し行だけを覆う**。ADR-135 が既に却下している。雛形の節名は地の文の列挙にも現れる（「背景・却下した選択肢・決定・帰結」）ので、見出し限定にすると本プラグイン自身の技能文書が咎められる。再監査でも `plugin/skills/` の 4 箇所でその形を確認した。
- **利用者に「節名を辞書へ入れるな」と運用で求める**。#197 の報告者が既に固有名の行という回避を強いられており、それを機構で解いたのが ADR-135 である。運用へ戻すのは後退である。
- **覆いを常に優先し続ける**（現状のまま）。二つ目の見逃しが残る。利用者が自分で禁じた語が黙って無効になるのは、辞書を単一の正本とする原則（ADR-005）に反する。

## 決定

覆いに**最長の字面が勝つ仲裁**を入れ、門を閉じる字面照合すべてに同じ覆いを掛ける。

1. 覆いの字面と、その検査がこれから探す字面を、一本の交替へ長い順に並べる。同じ位置では最長の字面が勝つ。**同点は覆いが勝つ** —— 節名は書き手が言い換えられないので、ADR-135 の限界はそのまま残す。正本は `plugin/scripts/_termcheck.py` の `_mask_arbiter`。
2. `_check_banned_synonyms` は禁止同義語を、`_check_calque` はカルクの字面を、それぞれ探す字面として渡す。
3. カルク表の字面の解釈（`／` の変種・末尾の `（…）`・先頭の `〜`）は `_calque_tokens` に一本化する。照合と覆いで二重定義しない。
4. 承認語による覆いの拡張は、渡された探す字面に対して判ずる（禁止同義語に固定しない）。

## 帰結

- 利用者の辞書が表A で禁じても表B で禁じても、登録簿の必須節名は書ける。全型・全節名の性質試験で凍結した（`plugin/tests/test_termcheck_calque_mask.py`）。
- 節名を含むだけの長い禁止語は、覆いに飲まれず発火する。これも全節名の軸で凍結した。
- **利用者の指摘内容が変わる**。表B に節名を持つ利用者は所見が消え、節名を含む長い語を禁じていた利用者は新たに所見が出る。後者は利用者自身が登録した字面の一致であって、推測による拡張ではない。配布物の変更履歴で告知する。
- 助言だけを残す側の検査（`CALQUE_WORDTRAP`・`UNDEFINED_TERM`）には掛けない。板挟みは門を閉じる所見どうしでしか起きない。射程をここで止める。
- 覆いの限界は残る。**固有名の行が禁止同義語と同じ字面のとき、その禁止は無効になる**（同点で覆いが勝つため）。辞書が自分と矛盾している状態であり、機械では正否を決められない。ADR-135 が節名の覆いを自動化した今、節名を固有名の行に書く回避は不要になったので、実害は縮んでいる。
- 登録簿が読めないときは節名の覆いが働かない。節の欠落の検査も同時に働かないので、板挟みの対は現れない（ADR-135 から不変）。
