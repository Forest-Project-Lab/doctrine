# 圧縮前の促しは届かない。退避の合図を圧縮後の注入へ移す

## 背景

`precompact-dump.py` は `PreCompact` で `hookSpecificOutput.additionalContext` に退避の
指示を載せて返していた。R12（会話知識の捕捉）の三本柱の一つ「圧縮前の退避」がこれである。

**現行の公式仕様では、`additionalContext` を運ぶ事象は決まっており、`PreCompact` はそこに
含まれない。** 2026-08-02 に再確認した。運ぶ先は次の三群だけである。

- `SessionStart` / `Setup` / `SubagentStart` — 会話の冒頭、最初のプロンプトの前
- `UserPromptSubmit` / `UserPromptExpansion` — 提出されたプロンプトの傍
- `PreToolUse` / `PostToolUse` / `PostToolUseFailure` / `PostToolBatch` — ツール結果の傍
- `Stop` / `SubagentStop` — ターンの末尾

`SPEC-022` は「PreCompact の注入が実行環境で届かない版でも、何も壊さない」と逃げを打って
おり、その限りで実装は正直だった。しかし**届かない「版」があるのではなく、構造上どの版でも
届かない**。すると次が成り立つ。

- R12 の三本柱のうち「圧縮前の促し」は、一度も発火したことのない死んだ経路である。
- `SPEC-025` の R12 行の一列が、空欄ではないのに実効ゼロで埋まっている。空セルを許さない
  検査は、文字が入っていることしか検めない。
- `NONGOAL-001` は「捕捉が保証するのは、セッションの終端と**圧縮前の促し**と、退避したメモの
  選別の義務まで」と宣言していた。その床は実際には無い。

R11「沈黙する故障の禁止」に照らせば、これは沈黙した故障そのものである。終了コード 0 で
無害な JSON を吐き、誰にも届かず、誰も気づかない。

## 却下した選択肢

**`PreCompact` が返す形を変えて届かせる。** 届かないのは形の問題ではなく、その事象が
文脈を運ばないからである。公式 schema に無いフィールドへ賭けるのは、同じ沈黙をもう一度作る。

**圧縮そのものを止める。** `PreCompact` は圧縮を拒否できず、拒否すべきでもない。

**フックが会話から決定を拾って書く。** フックは会話本文を持たない。持てたとしても、
会話の中の決定を機械が取りこぼしなく検出することは `NONGOAL-001` が引き受けないと定めて
いる。フックに書けるのは「圧縮が起きた」という事実だけである。

**`Stop` の終端確認で足りるとみなし、経路ごと畳む。** 終端の促しは圧縮を跨がない。長い
セッションでは、終端に達する前に詳細が失われる。合図を出す機会は残す価値がある。

## 決定

**届かない事象で促すのをやめ、「圧縮が起きた」ことをフックが機械的に残し、届く事象
（`SessionStart`）で圧縮の後に合図を出す。**

1. `PreCompact` のフックは `additionalContext` を返さない。代わりに、圧縮が起きた時刻を
   印（`_auditcache` の状態行。書き先は `${CLAUDE_PROJECT_DIR}/.claude/.cache`）へ原子的に
   残す。会話本文も推論過程も写さない。
2. `SessionStart` の注入が stdin の `source` を読む。`source` が `compact` のとき、保護節
   として合図を出す —— この会話は圧縮されており、圧縮前の詳細は失われている。いま思い出せる
   未記録の決定を `_system/.session-notes` へ書け。
3. 合図は圧縮の印が在ることにも依存させない。`source` が届かない実行環境でも、印が新しければ
   同じ節を出す（二重の入口。どちらか一方が生きていれば合図は出る）。
4. `SPEC-022` から「圧縮前に指示を注入する」を削り、上の二段へ書き換える。
   `SPEC-025` の R12 行の発火経路を実効のあるものへ改める。
5. `NONGOAL-001` の保証の床から「圧縮前の促し」を外し、「圧縮**後**の合図」に改める。
   保証しないことを正直に書き直す。
6. `EXT-001` に「`additionalContext` を運ぶ事象は限られており、`PreCompact` は含まれない」を
   依存として登録する。これは実行環境の仕様であり、機械で追えない。

## 帰結

- R12 の「圧縮を跨いだ捕捉」が、実効のある経路の上に載る。合図は圧縮の**後**になるので、
  圧縮で失われた詳細は戻らない。**弱くなったのではなく、もともと無かったものが可視になった。**
- `SPEC-025` の R12 行に、実効ゼロの列が無くなる。
- 保証限界: 圧縮の直前に何かを保存させることはできない。できるのは、圧縮の後に「失われた
  かもしれない」と告げることだけである。これは `NONGOAL-001` の「会話の中の決定を機械が
  取りこぼしなく検出することはしない」と同じ性質の限界であり、構造では埋まらない。
- 保証限界: `PostCompact` は使わない。`SessionStart(source=compact)` で足り、事象を増やす
  ほどの利得が無い。将来 `PostCompact` に文脈を運ぶ経路ができたら見直す。
