# 誤読の門を、全読者共通の床と、対象ごとに宣言する読者層に分ける（提案。手順書の正本は lens 側）

## 背景

H 層（人間が重大な誤読を検める門。ADR-112 決定2）は、被験者の層を宣言する口を持たない。
手順書の正本は doctrine-lens 側の `usability-tests/h-layer-protocol.md` に在り、本体系は
その合否を凍結の解除条件として引くだけである（ADR-112 決定5）。

issue #294 の Q4（同 issue が所有者へ問うた四つ目の問い）は「被験者一名を誰が担うか」を
問うた。所有者は 2026-08-14 の会話で、被験者は対象ごとに違う（PM（製品や案件の責任者）
から営業・経営層まで）ので、対象ごとに定められる方がよい、と述べた。

RESEARCH-005 が集めた外部の実証は、この見立てを支える。一義に書いても理解は読者で割れる。
背景知識には閾値があり、閾値の下では知識が読解へほとんど効かず、閾値を超えると強く効く
（標準化した回帰の係数で 0.18 と 0.81）。専門語を読む負担は、定義を添えても消えない。
初学者に効く冗長な説明は、熟達者には逆に働く。文章の側の統制の効き目にも限りがあり、その
効果は難しい文書と、母語でない読者・知識の少ない読者で最大になる。層を混ぜて測れば結果は
割れる（読み書きの層で正答率が 8.1% 対 77.8% に割れた実測がある）。「5 人で 85% を
見つける」という相場は、被験者が均質であることを仮定している。

外部の先行は、この二つを既に分けている。ANSI（米国国家規格協会）の安全標識の規格
Z535.3 は、正答率とは別枠で「意図と逆に取る誤読」を数え、上限を 5% と定める。
EU（欧州連合）の医薬品添付文書の可読性の試験は、偏りを避けるため医療の専門職を被験者から
外す。**誰が読んでも起きてはならない誤読**と、**読者によって変わる理解**は、別の物として
測られている。

いまの門は、この二つを一つの合否に畳んでいる。畳んだままだと、結果が割れたときに、割れが
記法の欠陥なのか読者の違いなのかを分けられない。

## 却下した選択肢

- **被験者の像を体系の側で一つに固定する**（例: doctrine を知らない開発者を一名）。対象
  ごとに読者が違うという観測に反する。経営層へ出す System Map の画面を開発者だけで測る
  ことになり、測っていない層について何も言えないまま「合格」の語だけが残る。
- **読者層を人物造形（ペルソナ。架空の一人を属性で組み立てた像）で書く。** RESEARCH-005 が
  集めた実証では、人物造形は代表性を検められず、属性を九つ以上組むと実在の合致者がゼロに
  なる。先行が実際に使う鍵は、読者の状況・課題か、熟達度・読み書きの実測である。
- **誤読の型も対象ごとに可変にする。** 床の四つの型は、保証の状態を逆に取る誤読と、希に
  しか出ない状態の誤読である。どちらも、読者が誰であっても「安全だ」と誤って読ませる。
  可変にすると「この対象では逆に読んでよい」という逃げ道になる。
- **何もしない。** 門は回るが、割れの出所が記録に残らない。「誰の理解を保証したのか」と
  いう問いに、実施のたびに答えられないままになる。

## 決定

以下は、doctrine が自分の門の条件をどう読むかの定めである。実施の作法と記録の形は
doctrine-lens 側の手順書の領分であり、本体系はそこへ提案しかしない（決定7）。

1. **誤読の門を二つに分ける。** 床は全読者に共通で固定し、読者層は対象ごとに宣言する。
2. **床は、手順書が定める太字の誤読（保証の状態に関する三つと、希にしか出ない状態に関する
   一つ。語の定義は doctrine-lens 側の手順書による）が 0 件であることとする。** 床は対象
   ごとに動かさない。
3. **凍結の解除（ADR-112 決定5）の判定に使うのは床だけとする。** 読者層の判定は、その対象
   の文言と投影の設計に使い、体系の型を増やす裁きには使わない。
4. **読者層は対象ごとに宣言されていることを求める。** 宣言は、読者の役割と、状況・課題・
   熟達の実測で書く。役割（PM・営業・経営層など）は所有者の指示に立ち、状況・課題・熟達の
   実測は RESEARCH-005 が示した先行の鍵である。人物造形では書かない。宣言の無い実施は、
   床の判定にだけ使える。
5. **判定は層ごとに読み、層を混ぜて平均しない。** どの被験者がどの層かが記録に残っていない
   結果は、層ごとの判定には使えない。
6. **保証の言い方を分ける。** 被験者数を伴わない「誤読 0 件」は、発見の停止則（新しい誤読が
   出なくなった時点で反復を止めてよい、という発見のための規則。保証の主張ではない）を
   満たしたという意味に留める。外へ「合格」を主張するときは、層と人数を併記する。
7. **本 ADR は手順書を改める権限を持たない。** 手順書の正本は doctrine-lens 側に在り、
   doctrine が決めるのは自分の門の条件の読み方だけである（リポジトリを越えた統治はしない。
   NONGOAL-001）。

## 帰結

- issue #294 の Q4 への doctrine 側の答えは「被験者は対象ごとに所有者が定める。凍結の解除の
  判定に要るのは、模型の作成に関与していない一名以上が床を通ること」となる。
- 手順書の改訂は doctrine-lens 側の領分であり、本 ADR の写しではなく提案として issue へ
  出す。合意と所有者の裁定を得た日に、本 ADR を受理する。
- **読者層の宣言をどこに書くかは、本 ADR では決めない。** 模型の中か対象の設定かは置き場の
  問いであり、ADR-161 が定める形（統治木の中の型付き .md）の下で決める。
- 本 ADR は ADR-112 を置換しない。決定2・決定5 は現行のまま効く。凍結の解除の裁きの記録は
  graph の側（ADR-111・ADR-112・EXT-006）に在り、本 ADR からは参照でだけ結ぶ——ドメインを
  越える依存は相手の ICD 宛だけに許されるためである（DECIDED-001）。
- 保証限界: 本 ADR は「理解が割れない」ことを保証しない。層を宣言すれば割れの出所が分かる、
  というだけである。
- 保証限界: 床の四つの型が誤読の全てだとは言っていない。RESEARCH-005 は網羅を主張していない。
- 材料の正本は RESEARCH-005 であり、本 ADR は結論だけを引く。RESEARCH-005 は平時の文脈に
  載らない（`llm_context: never`）。
