# 不変ガードも統治木の無い土地では発火しない

## 背景

ADR-036 は「統治木の無いプロジェクトでは二・三のガードは発火しない」と決め、その理由を
こう書いた。

> 依存の風のキーを持つ他体系（Obsidian 等）の Write/Edit を誤って deny/block しない。

そしてその文の中で、不変ガードについてこう述べている。

> 不変性ガードは統治木の中の archive/ADR にしか効かないため元から無影響。

**測ると、そうではなかった。** 統治木がどこにも無い土地でファイルを編集してみた。

| 木の外のファイル | 判定 |
|---|---|
| `type: ADR` ／ id が型を持つ形 | **deny**「既存ADR は改変できません」 |
| `type: ADR` ／ id 無し | **deny** |
| `status: archived` ／ 型なし | **deny**「アーカイブ済みの文書は不変です」 |

**doctrine を導入していない土地の、`type: ADR` と書いたメモが編集できない。**
ADR-036 が名指しした害（他体系の編集を誤って拒む）そのものが、不変ガードで起きていた。

置き場所による判定（`archive/` の下）は木を辿るので正しく無発火だった。**残っていたのは
フロントマターを読む二つの経路** —— 既存 ADR の改変と、`status: archived` の不変である。

ADR-036 の記述は**意図として正しく、事実として誤っていた。** 決定そのもの（二・三の
ガードを無発火にする）は生きているので置換しない。**足りていなかった側を足す。**

## 却下した選択肢

**記述を直して挙動を残す。** 「他体系の編集を誤って拒まない」という ADR-036 の意図に
反する。**意図の側が正しい。**

**ファイルが統治木の中に在るかで判ずる（`_is_under_docs`）。** 境界が二・三のガードと
食い違う。あちらは「**プロジェクト**に統治木が在るか」で判じており、木が在る
プロジェクトでは木の外の逸れた文書も点検する（受入がそれを凍結している）。
**逸れた ADR が編集自由になるのは緩め過ぎである。** 境界を三つのガードで揃える。

**何もしない。** 導入していない土地で拒まれるのは、この体系が「他人の木を裁かない」と
決めた線の越えである。しかも**理由の文が事実と食い違ったまま残る。**

## 決定

**不変ガードのフロントマターを読む経路も、プロジェクトに統治木が無ければ発火しない。**

1. **既存 ADR の改変の拒否と、`status: archived` の不変**は、プロジェクトに統治木が
   在るときだけ判ずる（二・三のガードと同じ `_project_has_tree` の境界）。
2. **置き場所による判定は変えない。** `archive/` の下は木を辿るので元から無発火である。
3. **木が在るプロジェクトでは、木の外の逸れた文書も従来どおり点検する。**
   緩めるのは「統治木がどこにも無い土地」だけである。
4. **読めない値での拒否（ADR-102）も同じ境界に揃える。**
5. **受入で凍らせる。** 木の無い土地で `type: ADR`・`status: archived` のファイルが
   編集できること、木が在れば従来どおり拒まれることを機械が見る。

## 帰結

- ADR-036 の意図が三つのガードで揃う。**他体系の土地を裁かない。**
- ADR-036 の理由の文にあった「元から無影響」は、事実ではなかった。**この ADR が
  その差を埋める**（決定は置換しない）。
- 保証限界: **統治木がどこにも無い土地では、不変は守られない。** そこに統治文書を置く
  なら、木を作ること。逸れた文書は木が在れば守られる。
- 保証限界: 境界の判定は木を上へ辿る形であり、`cwd` と対象のパスの両方から探す。
  **リンクや複数の木が絡む配置で、意図と違う木を拾う余地は残る**（ADR-022 の解決に
  従うが、そこまでは測っていない）。
- 保証限界: 木の無い土地で拒まないので、**そこに置かれた受理済み ADR は書き換えられる。**
  それは「他人の土地を裁かない」ことの対価である。
