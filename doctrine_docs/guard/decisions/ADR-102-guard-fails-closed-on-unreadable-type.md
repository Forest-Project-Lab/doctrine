# 型と位置づけ（`status`）を読めないとき、ガードは沈黙して開かない

## 背景

**受理済み ADR の本文を書き換えられた。** 型を一覧で書くだけでよい。

```text
type: [ADR]   の既存 ADR の本文編集 -> allow
type: ADR     の既存 ADR の本文編集 -> deny
```

同じことが `status` でも起きた。

```text
status: archived    の文書の編集 -> deny
status: [archived]  の文書の編集 -> allow
```

原因は、値をスカラへ正規化する関数が入れ物に対して内部表記（`"['ADR']"`）を返し、
それが `"ADR"` と一致しないことである。**ガードは「ADR ではない」と読んで通した。**

**正規化を正本化したら（ADR-101）、穴の一部が閉じた。切り分けて実測した。**

| 書き方 | 正本化だけ入れた状態 |
|---|---|
| `type: [ADR]` ／ id が型を持つ形（`ADR` の接頭辞） | **deny（閉じた）** |
| `type: [ADR]` ／ id が `X-1`（型を持たない） | **allow（開いたまま）** |
| `status: [archived]` | **allow（開いたまま）** |

一行目が閉じたのは、型を引く関数が**空なら id の接頭辞へ退避する**からである
（id の接頭辞から型を得る）。**当初この ADR には「正規化を揃えるだけでは直らない」と書いたが、
それは測る前の見立てで、誤っていた。** 型については、正本化と既存の退避で足りていた。

**残るのは二つで、芯は `status` である。** 位置づけには退避先が無い（id は状態を語らない）。
そして置き場所の判定は生きているので（`archive/` の下は型に依らず拒む）、
**倉庫の外に居る `status: [archived]` の文書だけが開く** —— ADR-027 が閉じたはずの穴の、
別の入口である。

**確定事実12 は「フックの境界は沈黙して開かない。判定を書けないときは阻止できる事象なら
終了コード2へ倒す」と定めている。** ここは判定を書けないのに、黙って開いていた。

## 却下した選択肢

**正本化（ADR-101）だけで済ませる。** 実測のとおり、`status` の穴と、型を持たない id の
場合が残る。**穴の一部が閉じたことを、閉じたと言わない。**

**位置づけにも id からの退避を用意する。** id は状態を語らない。**推測で状態を決めない。**

**入れ物の先頭の要素を読む（`['archived']` → `archived`）。** 寛容にすると、
**何が値なのかの答えが二つになる**（登録簿は文字列を値とする）。しかも `[a, b]` に答えが
無い。**寛容さで穴を塞がない。**

**リンタに任せる。** リンタは助言だけで、拒否しない（WATCH-001 第4項）。しかも**編集は
既に済んでいる。** 不変は編集の前に守らなければ意味が無い。

**終了コード2へ倒す。** 確定事実12 はそれを「阻止できる事象なら」の条件付きで許すが、
ここは PreToolUse で **deny を出せる事象**である。**拒否できるなら拒否する**のが強い側で
あり、終了コード2は判定を出せないときの最後の手段である。

**統治木の外でも拒む。** 木の外の `.md` に `type: [x]` と書く体系は在りうる
（ADR-036 の境界）。**外の土地では発火しない。**

## 決定

**統治木の中の既存文書について、`type` か `status` が在るのに文字列として読めないなら、
不変ガードは拒否する。**

1. **判定の前に読めるかを検める。** 統治木の中の既存ファイルで、`type` または `status` の
   値が在るのに文字列でないなら、**その場で deny する**（不変を判じられないから）。
2. **理由を告げる。** 「型／位置づけを文字列として読めないため、不変を判じられません」と
   鍵と値を添える。**黙って開かない。**
3. **統治木の外では発火しない**（ADR-036 の境界）。木の外の土地の慣習を裁かない。
4. **不在は対象にしない。** 鍵が無いのは別の欠陥であり（必須キーの検査の領分）、
   ガードの判定を止める理由にはならない —— 型が無いファイルは ADR でもアーカイブでも
   ないと読んでよい。**「無い」と「読めない」を分ける。**
5. **受入で凍らせる。** 一覧で書いた `type`・`status` が deny になること、素の値が従来
   どおり通ること、鍵の不在では止まらないこと、木の外では発火しないことを機械が見る。

## 帰結

- 受理済み ADR とアーカイブの不変が、値の書き方で外れなくなる。
- 型については正本化（ADR-101）で足りていたが、**この決定はその一段手前で止める** ——
  id の退避に頼らずに拒む。**退避が正しく働くかどうかに、不変を依存させない。**
- 保証限界: **覆うのは `type` と `status` だけである。** 他の鍵が入れ物で書かれても
  ガードは止めない（それらは不変の判定に使われない）。**使うようになったら足す。**
- 保証限界: **拒否は「読めない」ことに対してである。** 読めた値が正しいかは見ない
  （`type: SPEC` と偽って ADR の内容を書くことは止められない —— それは id と置き場所の
  検査の領分であり、ガードの受け持ちではない）。
- 保証限界: 木の外では発火しないので、**木の外に置かれた統治文書は守られない**
  （NONGOAL-001 第4項と同じ立場。全件監査が後から拾う）。
- 保証限界: 同じ書き方が ICD 依存ガード・削除安全ガードの判定を狂わせるかは測っていない。
  不変ガードが最初に当たるので**この経路では**三つのガードの入口が閉じるが、
  **他の経路（Bash の削除、PostToolUse の突き合わせ）は測っていない。**
