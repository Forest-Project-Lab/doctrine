# 読み取りの門を迂回しない。復号の寛容さは正本の引数で表す

## 背景

同名の関数を走査したところ、`_read_text` が三箇所に在った。中を見ると、**二本は正本へ
委ねる薄い前面で、一本だけが自前で開いていた。**

| 在処 | 中身 |
|---|---|
| `_termcheck` | 正本（`_frontmatter.read_text`）を呼ぶだけ |
| `docs-linter` | 正本を呼ぶだけ |
| **`term-extract`** | **自前で `open`。`errors="replace"` で寛容に復号する** |

自前で開く一本は、**通常ファイルの門を通っていない。** 確定事実12 と ADR-075 は
「統治対象を読む前に通常ファイルかを検める」と定め、そのために共有の読み手を置いた
（名前付きパイプ・デバイスを開いて戻らない類型を断つため）。

**届く。** 語の抽出は統治木を走査し、`.md` の一つずつを `_read_text` に渡す。
木の中に `.md` の名を持つ非通常ファイルが在れば、そこへ直に当たる。

ただし**寛容さは意図されたものである。** 説明文は「UTF-8 でない内容への頑健さ」と書き、
復号できない字を置き換えて走査を続ける。語の頻度を数える処理には妥当で、
**厳密に落とすべきではない。** 正本は厳密（復号の失敗は例外）であり、
**方針が違うだけで、門が要らないわけではない。**

## 却下した選択肢

**`term-extract` を正本の厳密な復号へ揃える。** UTF-8 でない一つのファイルで走査全体が
止まる。**意図された寛容さを壊す。**

**`term-extract` に門だけを足す（`ensure_regular` を呼んでから自前で開く）。**
門の呼び出しを呼び手が覚えることになる。**忘れれば静かに開く** —— いま起きているのが
まさにそれである。**門は正本が持つ。**

**薄い前面を残す。** ADR-099・ADR-101・ADR-104 で三度同じ判断をした ——
前面は後からそこで挙動を変えられる場所になる。実際、この三本のうち一本が
そうなっていた（前面のはずが自前の実装になっていた）。

**そのままにして註記する。** 註記は迂回を止めない。

## 決定

**復号の方針は正本の引数で表す。門は正本が持ち、呼び手は迂回しない。**

1. **正本に復号の方針の引数を足す。** 既定は厳密（いまの挙動）。寛容に読みたい呼び手は
   それを渡す。**門（通常ファイルの検め）は方針に依らず必ず通る。**
2. **`term-extract` は正本を寛容の方針で呼ぶ。** 意図された寛容さは残り、門を得る。
3. **薄い前面を消す。** `_termcheck` と `docs-linter` は正本を直に呼ぶ。
4. **機械が写しを咎める。** `_read_text` を正本の外に定義したら、メタの受入が落ちる。
5. **門が効くことは構造で凍らせる。** 正本が門を呼んでいることを見る
   —— **振る舞いでは測れない**（下記）。

## 帰結

- 統治木を読む経路が一本になり、門が全部に掛かる。
- 復号の方針の違いが、**引数として目に見える**（別実装として隠れない）。
- 保証限界: **門が効くことは振る舞いでは測っていない。** 名前付きパイプで戻らないことを
  測ろうとすると試験が止まる。ADR-104 と同じ扱いで、構造（正本が門を呼び、呼び手が
  素で開かない）を凍らせる。**測れないものを測ったふりにしない。**
- 保証限界: **寛容な復号は字を置き換える。** 置き換わった字は戻らない。語の頻度を数える
  用には足りるが、**正確な内容ではない**（正本の既定を厳密にしているのはそのためである）。
- 保証限界: 機械が咎めるのは名前の形である。別の名前で同じことをすれば掴めない。
